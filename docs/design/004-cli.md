# 004 — CLI

Goal: `nock` binary provides `check` with exit codes 0/1/2 and reads a file stats path.

Options
- Commander-based CLI wrapping `@nock/core`.
- Custom argv parser: no benefit.
- Composite GitHub Action-only: loses local dev story.

Decision
- Use commander; `nock check --sql <file> --stats <file> [--policy <file>] [--pg-version] [--format json|text] [--fail-on]`.
- Defaults: policy falls back to `policy.default.yml` JSON in Phase 1.
- Exit: 0 pass, 1 warn-only (yellow while fail_on=yellow), 2 fail.

Acceptance criteria
- Running against fixtures yields JSON verdict and exit 2 on Railway-shaped.
- Help text includes Nock branding.
