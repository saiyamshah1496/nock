# v0.1.8 — R024–R026 rule set (CLI + MCP + Core)

This release bumps all publishable `@nockhq/*` packages to 0.1.8 and ships rule refinements focused on free-path, check-only evaluation in CLI/MCP/Core. Hosted Worker/API does not evaluate these rules, so no Worker feature deploy is required.

Highlights
- R024 — Index density on large tables (CREATE INDEX / CIC; live+valid+ready count; large co-gate; neutralize if indexes omitted)
- R025 — Write-heavy index cost + estate write counters `n_tup_ins`/`n_tup_upd`/`n_tup_del` (sync-estate CLI+MCP; neutralize if counters missing; yellow/red thresholds)
- R026 — Per-index `columns[]` (omit when unknown) + redundant/left-prefix overlap detection (uniqueness matrix; live covering; v1 caveat on mixed expression keys)
- Note: soft nits from #68 are already on `main` (README row + `live===true`).
