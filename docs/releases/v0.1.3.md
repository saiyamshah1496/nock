# v0.1.3 — Hosted CLI flags

This release bumps all publishable `@nockhq/*` packages to 0.1.3 and includes the hosted-prefer CLI path from Team PR3.

Highlights:
- CLI now supports hosted estate + policy flags:
  - `--estate-api-url`, `--estate-api-token` (prefer hosted when a token is present)
  - Continues to support file fallback via `--estate` and `--policy`
- Docs and examples updated to use `npx @nockhq/cli@0.1.3`

Packages:
- `@nockhq/core@0.1.3`
- `@nockhq/secure-estate@0.1.3`
- `@nockhq/cli@0.1.3`
- `@nockhq/mcp@0.1.3`
- `@nockhq/api@0.1.3`

Note: Publishing to npm is coordinated separately.
