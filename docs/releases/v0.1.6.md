# v0.1.6 — R008/R009 deepen + MCP hosted parity/hardening

This release bumps all publishable `@nockhq/*` packages to 0.1.6 and includes:

- R008/R009 catalogue deepen (landed on main via [#54]) — expanded catalogue signals used by these rules.
- MCP hosted parity for Nock Team partners:
  - Hosted-first docs with `estateApiUrl` + token (`NOCK_TEAM_API_TOKEN`), no file download required.
  - Tool now delegates to a shared helper for hosted/local resolution.
  - Hardened fallback semantics to match CLI: when hosted fetch fails, fall back to `estatePath` if provided; otherwise surface a clear error (no silent empty-estate).
  - Hosted golden parity test ensures MCP verdict JSON ≡ shared-engine verdict for the same SQL and the same hosted estate/policy.

Pins and usage

```bash
npx @nockhq/cli@0.1.6 check --sql migrations/001.sql --estate .nock/estate.json --format json
```

MCP (agents), hosted-first:

```json
{
  "sql": "ALTER TABLE public.sessions ADD COLUMN last_seen_at timestamptz",
  "estateApiUrl": "https://nock.saiyamshah1496.workers.dev/v1/estate/owner/repo"
}
```

Environment variable for Team partners: `NOCK_TEAM_API_TOKEN` (aliases: `NOCK_ESTATE_API_TOKEN`, `NOCK_STATS_API_TOKEN`).
