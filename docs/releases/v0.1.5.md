# v0.1.5 — R022/R023 deepen + R007 yellow arm

This release bumps all publishable `@nockhq/*` packages to 0.1.5 and deepens the governance catalogue rules:

- R022 — VALIDATE CONSTRAINT: handle `VALIDATE CONSTRAINT` paths explicitly in analysis.
- R023 — invalid/not‑ready index: recognize invalid/not‑ready indexes in catalogue and project safer guidance.
- R007 — supporting‑index yellow arm: when a suitable supporting index exists, emit a yellow advisory instead of hard red in some paths.

On your side:

- Upgrade to CLI 0.1.5+ and keep your workflow pins updated.
- Re‑run `sync-estate` (and any scheduled `--push-url` jobs) so hosted/file estates include the latest catalogue.

Example:

```bash
npx @nockhq/cli@0.1.5 ...
```
