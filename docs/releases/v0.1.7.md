# v0.1.7 — Live estate refresh from DATABASE_URL (CLI + MCP)

This release bumps all publishable `@nockhq/*` packages to 0.1.7 and adds a free-path, check-only flow to refresh the estate live from a Postgres connection string without any hosted setup:

- CLI and MCP can read `DATABASE_URL` (or `--database-url`) to live-refresh the estate snapshot before evaluating a migration. This performs a read-only catalogue query; it does not apply migrations and does not push to any Worker or hosted API.
- A real Postgres CI job `live-estate-database-url` was added to exercise this flow end-to-end against a containerized database.
- A new guide, `docs/guides/live-estate-database-url.md`, documents how to run live checks locally and in CI, including examples for both failing and passing migrations.

Example (prefer `@latest` in docs and workflows):

```bash
npx @nockhq/cli@latest check \
  --sql examples/live-estate-database-url/bad.sql \
  --database-url "$DATABASE_URL" \
  --format json
```
