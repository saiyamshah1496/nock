# v0.1.9 — Deeper remediations for R002 / R015 / R023

This release bumps all publishable `@nockhq/*` packages to 0.1.9 and strengthens remediation guidance in Core for common index‑safety pitfalls, with direct `docs_url` links to anchored guidance. Hosted Worker/API does not evaluate these rules, so no Worker feature deploy is required.

Highlights
- R002 — Explicit guidance for "concurrent DDL cannot run in a transaction", with a `docs_url` to the Prisma migrations guide anchor.
- R015 — Recommend a short fail‑fast `lock_timeout` before `CREATE INDEX CONCURRENTLY` (Prisma cannot put the `SET lock_timeout` and CIC in the same migration file), with `docs_url`.
- R023 — Post‑deploy cleanup for invalid/not‑ready indexes (drop + rebuild concurrently), with `docs_url`.
- Prisma migrations guide: added explicit HTML anchors so links are stable from rule remediation text:
  - `#concurrent-ddl-cannot-run-in-a-transaction`
  - `#lock_timeout-before-cic`
  - `#invalid-or-not-ready-index-cleanup` ([see guide](../guides/prisma-migrations.md))
- Docs‑only addition: concise install + migration‑path guides for popular ORMs/migrators ([Prisma](../guides/prisma.md), [Drizzle](../guides/drizzle.md), [Flyway](../guides/flyway.md)) — no package changes.
